# 🔗 Linkboard

Linkboard is a full-stack web application that allows users to organize, manage, and search their links through collections.

## ✨ Features

- Create and manage collections
- Add links to collections
- Edit existing links
- Delete links
- Search links
- Frontend and backend integration
- Database integration
- REST API
- User-friendly interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Tools
- Git
- GitHub
- VS Code
